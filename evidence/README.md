# Milestone 1 evidence

The folders group project captures, reports, and exports by test. For the final hardware run, start with [Requirement 6, batch 35](requirement-06-normal-run/R06-Batch35-Verification.md). The report identifies actual Wireshark frame numbers, USB sequence numbers, and SQLite event IDs.

The published Test 5 disconnect capture contains only the ESP32 B connection. The published Requirement 5.6 capture contains the inspection connection and the validation proxy's loopback connection. Use each folder's `Wireshark-Frame-Map.csv` to translate original frame numbers to the published capture. The other captures retain their referenced frame numbering.
